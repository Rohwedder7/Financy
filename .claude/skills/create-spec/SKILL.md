# Create SPEC

1. Read `CLAUDE.md`, BND, PRD, business rules and traceability.
2. Select one observable outcome and copy `specs/templates/SPEC-template.md`.
3. Assign the next unique ID; cite exact RF/RNF/BR/ADR IDs.
4. Define scope, non-scope, contracts, edge cases and Given/When/Then acceptance.
5. Add executable verification commands and dependencies.
6. Update traceability and ask for approval before moving to `specs/active`.

Reject vague acceptance, multiple independent outcomes and undocumented product choices.
