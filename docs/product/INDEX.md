# Índice de produto

Esta pasta é a fonte de verdade do produto Financy. Em caso de conflito, prevalece a ordem: requisitos do desafio → decisão registrada em ADR → SPEC aprovada → código.

| Documento | Finalidade |
| --- | --- |
| [BND](./BND.md) | Necessidade de negócio, resultado e limites |
| [BNT](./BNT.md) | Alias de compatibilidade com o termo usado no guia anexado |
| [PRD](./PRD.md) | Requisitos funcionais e não funcionais |
| [Regras de negócio](./BUSINESS_RULES.md) | Regras estáveis com IDs |
| [Rastreabilidade](./TRACEABILITY.md) | Relação entre necessidade, requisito, SPEC e teste |
| [Inventário Figma](./FIGMA_INVENTORY.md) | Evidências visuais, tokens e pendências |

Não altere uma regra silenciosamente. Atualize o documento, a rastreabilidade e a SPEC afetada no mesmo pull request.
